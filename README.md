# NLTK_Chatbot
NLP Projects: ChatBot using NLTK
🚀 What I Learn
- Text Preprocessing: Tokenization, lemmatization, and POS tagging
- Feature Extraction: Bag-of-Words model for vectorizing text
- Classification Models: Decision Tree and Naive Bayes for intent recognition
- Chatbot Logic: Building a rule-based or model-driven response system
📦 Technologies Used
- Python
- NLTK
- Scikit-learn (for classification models)
- Regex and basic NLP utilities
Whether you're a beginner in machine learning or exploring NLP for the first time, this repo offers a practical foundation for building intelligent text-based applications
